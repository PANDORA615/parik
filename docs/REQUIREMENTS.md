# Соответствие ТЗ

Это карта исходников, а не протокол ручной приёмки. Фактические результаты исполнения — в VERIFICATION.md.

| Требования | Реализация |
|---|---|
| FR-001–010 расписание | `ui/Lists.kt`, `SalonViewModel`, `SalonApp`; дневной список + системный месячный выбор даты |
| FR-011–020 клиенты | `ui/Editors.kt`, `ui/Lists.kt`, `platform/Contacts.kt`, `SalonRepository.saveClient` |
| FR-021–025 услуги | `ServiceEditor`, `ServicesScreen`, `seedServices`; подтверждённое добавление без цен |
| FR-026–038 записи | `AppointmentEditor`, `AppointmentDetails`, `SalonRepository`, `Rules`; Room-транзакция, статусы, цена, подтверждённое удаление |
| FR-039–043 график | `SettingsScreen`, `Rules.slots/insideHours`; перерывы отложены, это указано в приложении и README |
| FR-044–048 напоминания | `platform/Reminders.kt`, `SettingsScreen`; WorkManager, runtime permission и нейтральный текст |
| FR-049–055 настройки/копия | `SettingsStore`, `BackupCodec`, `SalonRepository.restore/export`, SAF в `SettingsScreen`; нет сетевой передачи |
| AC-01/02/04/05/06/07/08/09/11 | Domain / Room / Compose tests; основные сценарии подтверждены Android CI; дополнительные ручные проверки отмечаются отдельно |
| AC-03 контакты | Системный picker реализован; OEM и несколько номеров требуют ручной проверки |
| AC-10 копия | Валидация, round trip, отклонение ошибки без изменений и журнал настроек покрыты тестами; SAF-поток требует ручной проверки |
| AC-12 уведомления | Реализация и CI-сборка; реальные задержки Doze/перезагрузка/разрешения требуют ручной проверки |
| Приватность | Нет INTERNET/READ_CONTACTS/CALL_PHONE; cloud backup и transfer исключены; JSON без шифрования с предупреждением |
| Производительность | Синтетический инструментальный тест 5000/20000 с замерами в артефактах CI; проверка на типичном физическом устройстве остаётся обязательной |

Архитектурные предположения: один мастер, один телефон; системная зона; RUB как редактируемая начальная валюта; рабочая неделя Пн–Пт 09:00–18:00; COMPLETED/NO_SHOW после начала визита; длительность до 7 дней; полный JSON restore до 20 МБ. Детали — ARCHITECTURE.md.
