# Фактическая проверка — 15 ноября 2026

## Выполнено локально

Среда: Linux x86_64, полный Temurin JDK 17.0.21+9, Gradle Wrapper 8.13, SDK Platform 36 / Build Tools 36.0.0. Исходный репозиторий был пустым.

Первый полный прогон `./gradlew assembleDebug testDebugUnitTest assembleDebugAndroidTest lintDebug` завершился `BUILD SUCCESSFUL`:

- debug APK собран: `app/build/outputs/apk/debug/app-debug.apk` (около 13 МБ);
- тестовый APK собран;
- 20 unit-тестов: 16 RulesTest + 4 BackupTest, 0 ошибок/падений;
- lint: 0 ошибок, предупреждения о версиях зависимостей и рекомендации по коду/ресурсам;
- Room сгенерировал схему v1, она включена в исходники.

После этого добавлены дополнительные инструментальные проверки, исправлены сохранение черновика настроек, формат валюты без дробной части, обязательность версии копии и обработка входа из уведомления. Итоговый повторный прогон выполняется; результаты будут уточнены.

## Ограничения среды и непроверенные пункты

Android 11 / API 30 эмулятор запущен с программной эмуляцией CPU: KVM отсутствует. Первая загрузка очень медленная. Появление ADB-устройства ещё не считается успешным запуском приложения. Инструментальные тесты пока не объявляются пройденными.

Попытка сборки debug + release + lint одновременно с эмулятором была завершена Linux OOM killer. Лимит Gradle уменьшен до 2 ГБ, компиляция Kotlin перенесена в процесс Gradle, повторный запуск идёт с одним worker. Это не результат успешной release-сборки.

Не подтверждены вручную: реальные Android 8/10/13/14/36, контактные провайдеры OEM с несколькими номерами, доставка уведомлений/Doze/перезагрузка/отказ разрешения, полный SAF-поток восстановления, TalkBack/крупный шрифт, время работы на типичном физическом устройстве. Отдельные перерывы отложены в рамках разрешённого ТЗ ограничения.
