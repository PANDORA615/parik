# Приватность

Приложение хранит на этом устройстве введённые мастером имена, телефоны, заметки клиентов, услуги, стоимость и историю записей. Аккаунта и отправки на сервер нет; INTERNET, READ_CONTACTS и CALL_PHONE не запрашиваются. Аналитики, рекламных и crash-reporting SDK нет. Приложение не выводит персональные данные в собственные логи.

Кнопка «Из контактов» запускает системный выбор одного человека. Читаются только разрешённые данным URI имя и доступные номера. Мастер видит предпросмотр, выбирает номер, исправляет поля и сохраняет локального клиента. URI контакта не сохраняется. При отсутствии разрешённого номера остаётся ручной ввод. Доступ ко всей книге не нужен. Звонок открывает системный номеронабиратель, который требует отдельного действия пользователя.

Данные Room и DataStore находятся во внутреннем каталоге приложения и защищаются стандартной изоляцией Android и блокировкой устройства. Отдельного PIN/биометрии внутри приложения в MVP нет. Автоматическое Android cloud backup и перенос базы исключены правилами приложения. Поведение переноса данных у конкретного производителя устройства требует проверки.

Экспорт JSON сохраняется только в выбранный мастером через системный диалог документ. Он содержит персональные данные **без шифрования**, о чём приложение предупреждает заранее. Сохраняйте его в защищённом месте, учитывайте синхронизацию выбранного файлового провайдера и не передавайте посторонним. Приложение само не выполняет автоматическую загрузку в облако.

Архивирование клиента/услуги скрывает его из обычного списка и нового выбора, сохраняя историю. Отмена визита также сохраняет историю; отдельное подтверждённое удаление визита удаляет его из локальной базы. Восстановление копии полностью заменяет данные после предупреждения и подтверждения. Старые экспортированные файлы при этом не удаляются: ими управляет пользователь в файловом менеджере.

Очистка данных Android или удаление приложения удаляет локальную базу и настройки. Сначала сделайте ручную копию, если информация нужна. Для полного удаления не забудьте самостоятельно удалить экспортированные JSON-файлы и их копии у файлового провайдера.

Владелец устройства определяет законные основания обработки, сроки хранения и информирование клиентов, в том числе по применимому законодательству о персональных данных/GDPR. Это описание технических свойств приложения, а не юридическое заключение. Для публичного выпуска потребуется утверждённая владельцем продукта политика.
