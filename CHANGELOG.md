# Изменения

## 1.0.0 — 2026-11-15

Первоначальная реализация Android MVP по ТЗ: локальная база, клиенты/услуги, календарь записей с транзакционным контролем конфликтов, контакты, график, WorkManager-напоминания, JSON-резервирование, русская Compose UI, тесты и GitHub Actions. Состояние проверки и оставшиеся ограничения указаны в docs/VERIFICATION.md.
