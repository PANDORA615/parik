# Изменения

## 1.0.1 — 2026-11-16

В «Добавить клиента» появились варианты «Из контактов» и «Ввести вручную» как в списке клиентов, так и при создании записи. Выбор контактов сразу запускает системную телефонную книгу; после сохранения клиент подставляется в начатую запись без потери даты, времени, услуги и стоимости. Отмена выбора оставляет ручное заполнение, пересоздание Activity не открывает picker повторно. Формат базы данных не изменён.

Добавлены UI-проверки отмены системного выбора и создания записи через этот путь. Успешно: 20 unit-тестов и по 23 инструментальных теста на API 26/29/30/33/34/36 (138 проверок). Workflow публикации поддерживает имена файлов для выбранной версии релиза.

## 1.0.0 — 2026-11-15

Первоначальная реализация Android MVP по ТЗ: локальная база, клиенты/услуги, календарь записей с транзакционным контролем конфликтов, контакты, график, WorkManager-напоминания, JSON-резервирование, русская Compose UI, тесты и GitHub Actions. Проверено: 20 unit-тестов и по 21 инструментальному тесту на API 26/29/30/33/34/36; APK/AAB успешно собраны. Состояние ручной приёмки и оставшиеся ограничения указаны в docs/VERIFICATION.md.
