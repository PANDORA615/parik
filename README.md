# Мой салон — Записи

Нативный Android-ежедневник одного парикмахера. Русский интерфейс, Android 8.0+, работа без интернета, база Room на устройстве. Исходное [техническое задание](docs/SPECIFICATION.md) включено без изменений.

## Что реализовано

- Расписание дня, «Сегодня», стрелки и системный месячный календарь, прокрутка, статусы текстом и цветом.
- Клиенты: ручное создание/редактирование, поиск по имени/телефону, проверка дубликатов с выбором, архив, история и количество завершённых посещений, ACTION_DIAL.
- Выбор одного системного контакта без READ_CONTACTS, предпросмотр и выбор из доступных номеров. Если телефон не предоставлен провайдером контактов, его можно ввести вручную.
- Услуги с длительностью, необязательной ценой/заметкой и архивом; пять начальных услуг предлагаются с подтверждением, без назначенных цен.
- Создание/перенос/редактирование записей, фактическая цена, отмена, завершение, неявка, отдельное удаление с подтверждением.
- Транзакционная защита от пересечений `[start, end)`, включая переход через полночь, исключение редактируемой записи и освобождение отменённого времени.
- Рабочие дни/часы, свободные слоты с шагом 15/30/60 минут по полной длительности, явное подтверждение вне графика.
- Приблизительные локальные напоминания WorkManager 15/30/60 минут, разрешение Android 13+, нейтральный текст уведомлений.
- DataStore-настройки, системная/светлая/тёмная тема; состояния форм сохраняются при пересоздании Activity.
- Версионированный JSON через системный выбор файлов, проверка размера/содержимого/ссылок, подтверждённая полная замена в транзакции и журнал восстановления настроек.

Автоматическая проверка: **20 unit-тестов + 126 инструментальных проверок** (21 тест на Android 8/10/11/13/14/16: Room, UI, напоминания и синтетическая база 5000/20000). [Успешный CI](https://github.com/PANDORA615/parik/actions/runs/43759109269). Фактические результаты сборки и тестов, а также непроверенные сценарии — в [VERIFICATION.md](docs/VERIFICATION.md). **Наличие функции в исходниках не означает ручную приёмку на всех Android-устройствах.**

## Скачать и установить

Готовый установочный APK: **[скачать my-salon-1.0.0.apk](https://github.com/PANDORA615/parik/releases/download/v1.0.0/my-salon-1.0.0.apk)**. AAB и контрольные суммы доступны на [странице релиза v1.0.0](https://github.com/PANDORA615/parik/releases/tag/v1.0.0). Другие сборки можно получить в [GitHub Actions](https://github.com/PANDORA615/parik/actions): откройте успешный запуск **Android**, скачайте артефакт **my-salon-apk-aab**, распакуйте и выберите `app-debug.apk`.

1. Перенесите APK на телефон с Android 8.0 или новее.
2. Откройте файл. При необходимости разрешите установку из выбранного браузера/файлового менеджера.
3. После установки отключите разрешение установки из неизвестных источников, если оно больше не нужно.
4. Откройте «Мой салон — Записи», выберите начальные услуги, проверьте рабочий график и валюту в настройках.
5. Создайте клиента, затем запись. Доступ к интернету или аккаунт не требуется.

Debug APK подписан отладочным ключом среды сборки. Ключи разных машин отличаются: обновление другим APK может потребовать переустановки. **До удаления приложения обязательно экспортируйте резервную копию**, затем восстановите её после установки. Для постоянного выпуска нужен собственный стабильный release-ключ. В репозиторий ключ не добавляется.

## Сборка в Android Studio

Откройте корень проекта в стабильной Android Studio с поддержкой AGP 8.13.2, используйте полный **JDK 17**. Установите SDK Platform 36, Build Tools 36.0.0 и Platform Tools через SDK Manager. Android Studio создаст локальный `local.properties`; его не нужно коммитить.

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest lintDebug
./gradlew connectedDebugAndroidTest  # нужен запущенный эмулятор или подключённый телефон
./gradlew assembleRelease bundleRelease
```

Windows: `gradlew.bat assembleDebug`. Первый запуск требует интернета для загрузки инструментов/библиотек; установленное приложение работает офлайн. Gradle Wrapper 8.13 и его SHA-256 включены, версии зависимостей зафиксированы в `gradle/libs.versions.toml`.

Результаты:

- `app/build/outputs/apk/debug/app-debug.apk` — устанавливаемый отладочный APK.
- `app/build/outputs/apk/release/app-release-unsigned.apk` — release APK, требует подписи вашим ключом.
- `app/build/outputs/bundle/release/app-release.aab` — bundle для дальнейшей подписи и подготовки публикации; это не файл для обычной установки на телефон.
- `app/build/reports/` — отчёты тестов и lint.

Google Play-публикация в эту задачу не входит. Перед публикацией нужны release-подпись, проверка текущих правил магазина, privacy policy и ручная приёмка.

## Данные и ограничения

Данные находятся во внутреннем каталоге Android. Интернет-разрешения, аналитики, рекламы, автоматической облачной копии и синхронизации нет. Удаление приложения/очистка данных уничтожает локальные данные. JSON-копия содержит персональные данные **без шифрования** — храните её в защищённом месте. Восстановление заменяет все данные после подтверждения; отмена и некорректный файл не меняют базу.

- Только PLANNED блокирует время, включая прошлые даты. COMPLETED/CANCELLED/NO_SHOW его не блокируют. Завершение и неявка доступны после времени начала.
- Визиты через полночь поддерживаются. При смене часового пояса сохраняется момент времени, меняется местное отображение. В повторяющийся час DST выбирается первое смещение.
- Телефоны нормализуются без угадывания страны: `8…` и `+7…` не считаются одним номером автоматически.
- Отдельные перерывы/блокировки, недельная сетка, онлайн-запись и многопользовательская работа пока не реализованы; месячный выбор даты доступен.
- WorkManager может задерживать напоминания; точность до минуты не гарантируется. Поведение контактов, разрешений и энергосбережения зависит от Android/OEM и требует проверок на целевых устройствах.
- Размер импортируемой копии ограничен 20 МБ, длительность визита — 7 днями.
